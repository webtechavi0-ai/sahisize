More and more exam forms now ask for certificates as a **PDF**, not as a photo. NTA exams want each certificate as a PDF of 50–300 KB. RRB wants the SC/ST certificate as a PDF under 400 KB. And the portal usually takes **one file per certificate** — so a two-page marksheet must go in as one PDF, not two images.

This guide shows how to do it with just a phone: scan the pages, join them in the right order, and bring the file under the limit without making the text unreadable.

## How big can the PDF be?

Here are the limits from recent notices. Always check the latest official notice — limits change between cycles.

| Exam | Document | Format | Size |
| --- | --- | --- | --- |
| [NEET UG](/exam/neet-ug) | Class 10 certificate, category, PwD/UDID, address proof | PDF | 50–300 KB each |
| [JEE Main](/exam/jee-main) | Class 10 certificate / marksheet, PwD/UDID | PDF | 50–300 KB each |
| [CUET UG](/exam/cuet-ug), [UGC NET](/exam/ugc-net) | PwD/UDID certificate | PDF | 50–300 KB |
| [CSIR NET](/exam/csir-net) | Category, PwD, result-awaited form | PDF | 50–300 KB each |
| [RRB NTPC](/exam/rrb-ntpc), [RRB ALP](/exam/rrb-alp), [RRB Group D](/exam/rrb-group-d) | SC/ST certificate (free travel) | PDF | under 400 KB |
| [IBPS PO](/exam/ibps-po) | Class 10 certificate | PDF, A4 | up to 500 KB |
| [UPSC CSE](/exam/upsc-cse), [NDA](/exam/nda), [CDS](/exam/cds) | Photo ID card | PDF (check the form) | Not confirmed — check the notice |

Notice two things:

- There is often a **minimum** too. NTA rejects a PDF below 50 KB. A very small file usually means the scan is too blurry to read anyway.
- **300 KB is the number to beat** for most NTA forms. Stay a little under it: some portals count 1 KB as 1,000 bytes. SahiSize keeps a small safety margin, so a 300 KB limit gives a file of about 280–290 KB.

## What you need

- The original certificate (not a photocopy, unless the notice allows it).
- A flat, well-lit table — daylight near a window is best.
- Your phone.

## Step 1: Photograph each page properly

1. Lay the page flat. If it curls, put a book on the corners outside the frame.
2. Hold the phone **straight above** the page, parallel to it. A tilted phone makes text slant and look stretched.
3. Fill the frame with the page, leaving a thin margin so no edge is cut. Portals reject certificates with **cut edges**.
4. Turn the flash off. It makes a white glare spot right on the text or the stamp.
5. Check that the seal, signature of the issuing officer and certificate number are all sharp. Zoom in on the photo to check.
6. Repeat for every page, front and back if the back has anything printed.

Do not take a screenshot of a certificate from DigiLocker and then shrink it hard — screenshots carry the phone's status bar and often look too small. If you have the original PDF from DigiLocker or the issuing website, use that directly and only compress it (step 4).

## Step 2: Put pages in the right order

The person checking your form reads page 1 first. Keep the order the way the certificate was issued:

1. Page with your name and certificate number first.
2. Continuation pages next.
3. Back side (if it has text or stamps) after its front.

One certificate = one PDF. Do not mix your category certificate and your Class 10 marksheet in the same file unless the form clearly says "upload all documents in one PDF".

## Step 3: Make the PDF

Open [Images to PDF](/tools/images-to-pdf) on SahiSize.

1. **Add your page photos** with **Take photo** or **Choose from gallery** — up to 20 files. You can add a PDF too; its pages are included. Nothing is uploaded to our server.
2. **Put them in order.** Drag the rows or use the up and down buttons.
3. **Pick A4** as the page size. IBPS asks for A4 directly, and A4 is the safe choice for every other portal. *Original size* keeps each image's own size, with no white border.
4. **Keep "Limit the file size" on and set the maximum** — for example 300 KB for NTA, or 399 KB for RRB. If the first try is too big, image quality and size are lowered step by step until the PDF fits.
5. Tap **Make PDF** and check the tick on the size row, then download. The file is named like `documents-300kb.pdf`; rename it if the portal wants a simple name.

There is no rotate button, so take each photo upright. If a page is sideways, rotate it in your phone's gallery first. The tool sets only a maximum: if your form also has a minimum (NTA wants at least 50 KB), check that the size shown is above it.

## Step 4: Already have a PDF that is too big?

A PDF downloaded from DigiLocker or a university site is often 1–3 MB because it holds a big colour scan. Use [Compress PDF](/tools/compress-pdf):

1. Pick the PDF.
2. Set the maximum KB (for example 300).
3. Let it compress, then open the result and **zoom in on the smallest text**. If you can read the certificate number and the date, it is fine.

If the text turns blurry before the file gets under the limit, the problem is usually a page with lots of colour background (like a coloured border or watermark). Rescan that page in better light so the background comes out white, or use your scanner app's black-and-white mode, and remove a blank back page if one is included.

## How much space does each page get?

A quick rule of thumb: divide the limit by the number of pages.

- 300 KB, 1 page → up to ~300 KB for that page. Easy.
- 300 KB, 3 pages → ~100 KB per page. Still readable if the scan is clean.
- 300 KB, 6 pages → ~50 KB per page. Text must be scanned well, on a white background.

If you have many pages, check whether the notice really wants all of them. Many forms only want the first page of a marksheet or the page with the category details.

## Common mistakes

- **Uploading a JPG where a PDF is asked.** The portal will say "invalid file type". Read [JPG vs PNG vs PDF](/guides/jpg-vs-png-vs-pdf) for which document goes in which format.
- **Password-protected PDF.** Some DigiLocker downloads are locked. Portals cannot open locked PDFs. Save or print to a new PDF first.
- **Over-compressing.** A 40 KB certificate that no one can read is worse than none. Stay above the minimum and check by zooming in.
- **Old or expired certificate.** RRB asks for a certificate valid on the closing date. A size fix does not fix an expired document.

## Before you upload

Use this quick check for each PDF:

1. Opens without a password.
2. Size is inside the range (for example 50–300 KB).
3. All pages are there, in order, the right way up.
4. Name, number, date, seal and signature are readable when zoomed in.
5. File name is simple, like `class10.pdf` — no spaces or special characters.

## FAQ

### My certificate has only one page. Do I still need to make a PDF?

Yes, if the form asks for PDF. Add the single photo to [Images to PDF](/tools/images-to-pdf) — a one-page PDF is perfectly fine.

### Can I scan in colour?

You can, but colour takes more KB. For a black-and-white printed certificate, your phone scanner app's black-and-white mode keeps the text sharper within 300 KB; then add those scans here. SahiSize keeps the colours you give it. Use colour if the notice asks for it or the stamp is unreadable without it.

### The portal says the file is too small. What now?

NTA has a 50 KB minimum. Make the PDF again with a higher maximum (or with the limit turned off), so the tool keeps more detail, and check that the size shown is above 50 KB.

### Is the ID proof also a PDF?

Not always. For JEE Main, CUET and CSIR NET, the identity proof is a **JPG** of 10–200 KB. For UPSC the photo ID is described as a PDF, but the size limit is not confirmed — check the field on the form. Check your exam page for each document.

### Are my certificates uploaded to SahiSize?

No. The PDF is created inside your browser. SahiSize is an independent tool and is not linked with NTA, RRB, IBPS, UPSC or any exam body. Always check the latest official notice.
